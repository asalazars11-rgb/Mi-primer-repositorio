# Mi-primer-repositorio
# Resumen de Datos – Ventas y Clientes

Este repositorio incluye dos archivos en formato **CSV** que contienen información actualizada sobre ventas realizadas y clientes registrados. Los datos están organizados para facilitar prácticas de análisis, visualización y manejo de información dentro de GitHub.

---

## Datos_ventas.csv

Este archivo contiene un conjunto renovado de registros de ventas realizadas en distintas fechas y sucursales.

**Columnas incluidas:**
- **Fecha:** Día en que se efectuó la venta  
- **ID_Venta:** Identificador único de cada transacción  
- **Producto:** Artículo adquirido  
- **Categoria:** Tipo de producto (Electrónica, Alimentos, Bebidas, Hogar, etc.)  
- **Cantidad:** Número de unidades compradas  
- **Precio_Unitario:** Valor por unidad  
- **Total_Venta:** Total calculado de la transacción  
- **Vendedor:** Persona encargada de la venta  
- **Sucursal:** Ciudad donde se realizó la compra  

Este dataset permite analizar tendencia de productos, rendimiento por vendedor y variación de ventas por sucursal.

---

## Datos_clientes.csv

Archivo actualizado que contiene información de clientes registrados recientemente.

**Columnas incluidas:**
- **ID_Cliente**  
- **Nombre**  
- **Apellido**  
- **Correo** electrónico  
- **Teléfono**  
- **Ciudad**  
- **Fecha_Registro**  

Este archivo permite identificar clientes, clasificarlos por ciudad y realizar análisis básicos de segmentación.

## Objetivo del Repositorio
